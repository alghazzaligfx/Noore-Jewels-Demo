# Nooré Jewels — Fresh GitHub Pages Project

A responsive jewellery-house website demo by Al Ghazali GFX.

## Files
- `index.html` — website structure and product image placements
- `style.css` — responsive design
- `script.js` — mobile navigation and collection filters

## Images and content restrictions
All image URLs point to individual Pexels product photographs checked for this demo. The selected photographs show jewellery objects only (rings, necklace, bracelet and jewellery sets); no people, women, men, faces, hands, bodies, animals or other living beings are used.

Images are hotlinked from Pexels CDN, so an internet connection is required for them to load. Each image is credited by its source page below. Please keep attribution/source notes with the project and re-check the Pexels license before using this demo commercially or replacing sample imagery with client products.

## Publish on GitHub Pages
1. Create a new **Public** repository, for example `Noore-Jewels-Demo`.
2. Extract this ZIP on your computer.
3. Upload `index.html`, `style.css`, `script.js` to the repository root (same level).
4. Commit changes.
5. Open Settings → Pages.
6. Select `Deploy from a branch`, branch `main`, folder `/ (root)`, then Save.
7. After deployment, the site should be available at `https://YOUR-USERNAME.github.io/Noore-Jewels-Demo/`.

Important: this project intentionally keeps the three code files at the repository root. No `assets` folder is required because the photos are loaded from the verified Pexels CDN image URLs.
